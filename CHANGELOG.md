## [1.1.2] - 2026-09-03 — maintenance release preparation

### Changed

- Advanced the backend Maven project version to `1.1.2`.
- Advanced the frontend npm package version to `1.1.2`.
- Began the post-`1.1.1` maintenance line without rewriting published release history.
- Corrected release-facing documentation so `v1.1.1` is represented as the published stable baseline and `v1.1.2` is the next maintenance target.
- Added repository-managed `v1.1.2` release notes for the tag-scoped release workflow.

### Verification

- The release version guard remains responsible for backend, frontend, and frontend lockfile root synchronization.
- The committed frontend lockfile must be regenerated by the supported npm workflow after the frontend manifest version changes.
- The tag-scoped release workflow remains the publication gate for packaged backend/frontend artifacts and checksums.

### Release status

- `v1.1.2` is the active maintenance release target.
- `v1.1.1` remains a published stable release and must not be rewritten or force-moved.

## [1.1.1] - 2026-09-03 — published stable release

### Changed

- Advanced the backend Maven project version to `1.1.1`.
- Advanced the frontend npm package version to `1.1.1`.
- Synchronized the generated frontend lockfile with the release version through automated npm lockfile generation.
- Extended the executable release-version guard to validate the frontend lockfile root metadata.
- Added repository-managed `v1.1.1` release notes and configured release automation to publish those prepared notes instead of generating an unrelated automatic description.
- Preserved all earlier release tags and historical engineering work without rewriting published history.

### Verification

- The release workflow validated the tag against frontend, backend, and lockfile versions before build work.
- The tag-scoped release pipeline was used to package the backend/frontend and generate checksums.
- Security, dependency, recovery, browser smoke, and accessibility evidence remain operational quality requirements for continued development.

### Release status

- `v1.1.1` is published as a stable release.
- `v1.1.2` is the next maintenance target.

### Product capabilities already present in the engineering line

- Responsive React/TypeScript application with authenticated role-aware navigation.
- Staff and member dashboards.
- Catalog search, book/copy administration, barcode/QR/accession lookup, and branch-aware availability.
- Member administration and account linkage workflows.
- Administrator staff-account management for account creation, role filtering, enable/disable control, password reset, and active-session visibility.
- Issue, return, renewal, reservations/waitlists, fine assessment/settlement, and configurable circulation policies.
- Reporting dashboard, overdue views, audit views, and CSV import/export workflows.
- Mock-safe and SMTP notification adapters.
- PostgreSQL schema managed through Flyway migrations.
