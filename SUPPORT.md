# LibraCore Support

## Where to ask

- Usage, setup, and bug reports: GitHub issues in this repository.
- Security vulnerabilities: follow [`SECURITY.md`](SECURITY.md); do not post exploitable details publicly.
- Support email: **supportramsandesh@gmail.com**
- Business/project contact: **sanskarin@outlook.in** or **sanskarin.business@gmail.com**
- GitHub profile: https://github.com/sanskarIN

## Before reporting a bug

Please include:

- LibraCore version or commit;
- operating system/browser where relevant;
- Java, Maven, Node.js, npm, PostgreSQL, and Docker versions relevant to the failure;
- exact command/action that failed;
- sanitized logs/error text;
- whether the issue reproduces from a clean checkout.

Remove passwords, bearer tokens, SMTP/database credentials, real member data, and private infrastructure details before sharing logs or screenshots.

## Troubleshooting

Start with [`docs/troubleshooting.md`](docs/troubleshooting.md) and [`docs/setup.md`](docs/setup.md). For database recovery, use [`docs/backup-restore.md`](docs/backup-restore.md) and test restores on an isolated database before touching production.
